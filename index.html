4. Computer Science Trade-offs & Deep Dive

Fundamental technical tensions inherent in intent-based AI software engineering.

1

Hallucination vs. Architectural Drift

As prompt chains grow, agents risk circular dependencies, duplicated utility functions, and deprecated library methods.

Mitigation Strategy: Strict test suites (pytest, vitest), clean git worktree rollbacks, and automated AST validation.
2

Context Window vs. Token Cost

Feeding entire repositories to LLMs exceeds context limits and skyrockets API costs without sparse indexing.

Mitigation Strategy: Model Context Protocol (MCP) servers, RAG vector embeddings, and AST-pruned dependency trees.
3

Determinism vs. Stack Flexibility

In-browser builders guarantee compilation through fixed frameworks (React+Tailwind+Supabase) at the cost of customization.

Mitigation Strategy: Use Layer 1 for rapid prototypes; export to Layer 2 IDEs (Cursor/Antigravity) for custom production stacks.
